# Marketing Campaign Performance

## Objective
Compare fictional marketing campaigns by click-through rate, conversion rate, cost per conversion, and spend.

## Tools
Python, Pandas, Matplotlib. SQL queries are included for practice.

## Run
1. Install Python 3.
2. Open terminal in this folder.
3. Run `pip install pandas matplotlib`
4. Run `python analysis.py`

## Questions
- Which channel has the best click-through rate?
- Which campaign has the lowest cost per conversion?
- How do conversion rates compare?
